# Saif Buheis — Portfolio

Static single-page site. No build step, no dependencies.

## Files

- `index.html` — the whole site
- `site.js` — nav scroll-spy, disclosure markers, click-to-play video facades
- `assets/` — portrait and project figures

## Deploy on GitHub Pages

1. These files live at the repository root on `main`. Keep them there — Pages only serves from `/` or `/docs`.
2. Settings → Pages → Build and deployment → Source: *Deploy from a branch*.
3. Branch: `main`, folder: `/ (root)`. Save.

The site will be live at `https://sbprjcts.github.io/PortfolioWebsite/`.
